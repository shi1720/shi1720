# Public project index

A directory of runnable products, smaller reference tools and upstream assessment material. Each repository documents its own setup, validation and operating limits.

## Products and evaluation systems

| Project | Purpose |
| --- | --- |
| [RepoGauntlet](https://github.com/shi1720/repo-gauntlet) | Validate coding-agent benchmark tasks with broken, incomplete and golden controls across Python, Java, Rust, C++ and TypeScript. |
| [OfferLoop](https://github.com/shi1720/offerloop) | A job-search CRM with AI-assisted drafts, application pipelines, follow-up reminders and funnel analytics, built on FastAPI and Google Cloud. |
| [StepFree](https://github.com/shi1720/stepfree) | An accessibility-repair workflow that combines coding agents with independent scans, content-integrity checks and human review. |
| [Plot Twist](https://github.com/shi1720/plottwist) | A playful personality sitcom with explainable scoring, original characters, private local answers and shareable result cards. |
| [Mixed Signals](https://github.com/shi1720/mixed-signals) | An anonymous dating-experience experiment with a living globe, privacy-aware aggregation and reproducible engineering evaluations. |

## Smaller reference tools

These tools document focused workflows from earlier projects. External integrations require current credentials and service access. They are not presented as independently verified production services.

| Repository | Purpose |
| --- | --- |
| [Math Question Editor](https://github.com/shi1720/math-question-editor) | Edit, preview and export math question banks without manually restructuring each question. Supports JSON, tabular review and PowerPath-compatible output. |
| [Speechace Scoring Proxy](https://github.com/shi1720/speechace-proxy) | Keep pronunciation-scoring credentials server-side while forwarding bounded audio uploads to Speechace. |
| [SAT PDF to CSV](https://github.com/shi1720/sat-pdf-to-csv) | Extract text from SAT question PDFs and use a model-assisted parsing step to produce a reviewable CSV question bank. |
| [AP Article Review](https://github.com/shi1720/ap-article-review) | Review batches of AP learning articles against configurable quality prompts, inspect model feedback and export review results. |
| [AP Free-Response Question Review](https://github.com/shi1720/ap-frq-review) | Review AP free-response questions in batches using configurable evaluation prompts, parallel requests and downloadable feedback. |
