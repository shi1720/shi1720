# Public project index

The source behind [the Working Atlas](https://shi1720.github.io/shi1720/). This is a September 2026 snapshot. Each repository documents its own setup, tests, external dependencies, and operating limits. Experimental health and legal tools are not presented as validated professional services.

## Agent infrastructure

| Project | What it explores |
| --- | --- |
| [KindHandoff Guard](https://github.com/shi1720/kindhandoff-guard) | MIT-licensed TypeScript guard for explicit handoff acceptance, auditable state transitions, and explainable candidate ranking. Zero runtime dependencies. |
| [RepoGauntlet](https://github.com/shi1720/repo-gauntlet) | Validate coding-agent benchmark tasks with broken, incomplete and golden controls across Python, Java, Rust, C++ and TypeScript. |
| [RepoGym](https://github.com/shi1720/repogym) | Turn any git repository into a verifiable RL environment for coding agents. Declarative tasks, gym-style env, composable graders, task validation and mining. |
| [Casecrop](https://github.com/shi1720/casecrop) | A Python library for reducing failing event traces into smaller regression cases, with dependency checks and replay evidence. |
| [Agent Rehearsal](https://github.com/shi1720/agent-rehearsal) | Reproducible fault testing for agent tools: retry policy simulator, local trace inspector, and Python SDK. |
| [Toolstorm](https://github.com/shi1720/toolstorm) | Deterministic tool failures, side-effect contracts, and strict offline replay for Python agents. Zero runtime dependencies. Interactive Python-powered lab. |
| [StepFree](https://github.com/shi1720/stepfree) | An accessibility-repair workflow that combines coding agents with independent scans, content-integrity checks and human review. |
